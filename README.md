# 培英國中 學生常規優缺點管理系統 (導師工作台 & 學生家長查詢專區)

專為國中導師日常班級經營量身打造的現代化常規管理系統。

---

## 🌟 核心特色與功能說明

### 0. 首頁智慧身分分流大廳 (Landing Portal)
- **進入頁面即時分流**：首頁直覺呈現兩大主要入口，供使用者依身分快速切換：
  - **👨‍🏫 導師工作台**：選定班級後直接進入日常常規登記、座號盤與總表管理。
  - **👨‍👩‍👧 學生 / 家長查詢專區**：免姓名、免密碼，僅憑個人隨機代碼登入，保障隱私安全。
- **隨時一鍵切換**：在各個頁面頂部導覽列皆有「🏠 返回身分分流」或點擊品牌 Logo 即可回到分流大廳。

### 1. 獨立校務管理者登入與系統管理中心 (Admin Console)
- **獨立管理者入口與專屬密碼**：
  - 管理者入口獨立設置於分流大廳頁尾及頂部導航列，避免與一般師生功能混雜。
  - 具備專屬密碼保護（**系統初始預設密碼：`admin888`**），登入後可於管理設定中隨時變更密碼。
- **幫所有老師進行頁面管理與基本資料設定**：
  - **👨‍💻 進入工作台代管模式**：管理者可一鍵以任何一位老師的身分進入其工作台，直接代為操作、登記、檢視總表或排解問題，並可隨時一鍵返回管理中心。
  - **🏫 班級與老師基本資料維護**：在管理中心直接編輯班級名稱、導師姓名、學校名稱與學生人數上限（建議標準 35 人），或新增/刪除班級。
  - **👥 各班學生名冊與代碼管理**：集中管理全校任一班級的 1 ~ 35 號名冊，支援批次從 Excel 貼上、單一/全班代碼重整、列印家長通知小卡。
  - **📢 常規項目全域標準同步**：管理者設定一套標準校規項目後，可一鍵同步套用至全校所有老師的班級中，省去各班重複輸入的時間。
  - **📅 段考週期集中管理**：支援單班切換或「全校統一開啟新段考」，全校班級常規即時歸零並重新累計。
  - **💾 全校資料備份與還原**：一鍵匯出全校所有班級 JSON 完整備份檔，保障資料安全。

### 2. 每日快速常規登記 (座號 1 ~ 35 號)
- **1 ~ 35 號互動座號盤**：大按鈕設計，支援單選、多選、全選或輸入座號多選（如 `1, 3, 5-8`），在教室觸控螢幕或手機上點選極為流暢。
- **即時數值顯示**：每個座號卡片上即時顯示該生在「目前段考」的缺點與優點累計數；若累積達 15 次，座號盤會亮起紅色警戒框與驚嘆號。
- **缺點 / 優點獨立登記**：依照需求無功過相抵，各自分立記錄。
- **即時撤銷流水帳**：右下方顯示最近登記的常規流水帳，若不小心按錯，可一鍵點選「撤銷」立即移除紀錄。

### 3. 學生/家長專屬代碼查詢專區 (個資隱私保障)
- **隨機專屬代碼**：每位同學由系統自動生成一組獨一無二的專屬英數代碼（例如 `PY801-02B`）。
- **零個資外洩風險**：家長與學生無需輸入真實姓名或身分證字號，僅需輸入該代碼即可查詢。
- **個人專屬常規歷程**：登入後可查看當前段考的缺點次數、優點次數、距離 15 次警告尚餘次數，以及每一筆詳細的違規/表揚時間與備註說明。完全看不到其他同學的紀錄，避免相互比較。
- **一鍵列印家長通知小卡**：導師可在後台點選「🖨️ 列印家長代碼通知小卡」，自動排版產生 A4 紙張大小的 35 張裁切條，方便印出貼於聯絡簿上發給家長。

### 4. 缺點累積滿 15 次警告提醒與生教陳報
- **15 次門檻預警系統**：
  - 累積滿 15 次：系統即時跳出提醒視窗，導覽列亮起紅色動態警示 Badge，首頁橫幅以紅色高對比警示。
  - 接近 12 ~ 14 次：顯示黃色警戒標籤，提醒導師可提早聯絡家長或個別晤談。
- **生教組警告陳報單一鍵生成**：點擊「📄 開立警告單」，系統會自動格式化整理該生班級、座號、姓名、所有違規日期與事由流水帳，並備有導師、生教組、學務主任簽章欄，可直接列印送出懲處。

### 5. 段考週期累積與歸零機制 (約 1 個月)
- **無功過相抵機制**：優點與缺點各自獨立累計，缺點不會被優點扣減。
- **段考歸零重計**：導師在段考結束後，可一鍵新增或切換至「第2次段考」、「第3次段考」，全班的常規累積即時歸零並重新統計。
- **歷史紀錄永久保存**：過去段考的每一筆紀錄皆完整保留，導師在「全班常規總表」中可隨時切換查閱歷次段考或「全學期總計」。

### 6. 學生基本資料庫管理 (上限 35 人)
- **座號 1 ~ 35 號名冊**：支援直接在表格中點選修改姓名。
- **Excel 批次貼上匯入**：點選「📋 批次貼上姓名」，直接從 Excel 或學籍系統複製 35 位名冊貼上，一秒完成名冊建置。
- **代碼隨機重設**：可隨時單獨或全班重新隨機生成代碼。

### 7. 自訂常規項目功能
- 導師可自由新增、修改、刪除自己班級的常規項目：
  - **缺點類預設**：遲到進教室、未交作業、聯絡簿未帶、上課擅自喧嘩、趴睡、服裝不整、打掃偷懶、座位髒亂、走廊奔跑、態度不佳等。
  - **優點類預設**：熱心助人、打掃認真、課堂發言優良、作業整潔獲甲上、拾金不昧、擔任幹部盡責、維護秩序等。
- 支援分類標籤（如：課堂秩序、學業常規、生活衛生、品德態度）與自訂次數權重。

### 8. 多班級與多老師資料庫支援
- 支援建立多個班級資料庫（如：8年1班、8年2班、705班...），不同老師可各自管理自己的班級，資料互不干擾。
- **資料備份與轉移**：支援「📥 下載全系統備份 (JSON)」與「📤 匯入還原備份」，老師可輕鬆將資料從學校電腦備份回傳至個人筆電。
- **匯出 Excel (CSV)**：全班總表支援一鍵匯出為標準 CSV 格式，方便用 Excel 進行統計與存查。

## 🚀 如何開啟與使用

本系統採用純前端架構（Vanilla HTML5 + Modern CSS + ES6 JavaScript + LocalStorage 離線持久化）：

1. **本機直接開啟使用**：
   - 在專案資料夾中，直接雙擊滑鼠左鍵開啟 [`index.html`](index.html)。
   - 支援所有現代瀏覽器（Google Chrome、Microsoft Edge、Safari 等）。
   - **不需安裝 Node.js、Python 或任何後端伺服器**，雙擊即可直接離線使用。
2. **透過本機伺服器預覽**：
   - 可使用 VS Code 的 Live Server 套件，或於終端機執行 `npx serve .` 啟動本地 HTTP 預覽。
3. **雲端發布（供學生與家長在家查詢）**：
   - 支援透過 **GitHub Pages** 一鍵自動發布（詳見下方說明），亦可上傳至學校內部網站伺服器。

## 🌿 環境變數設定 (.env)

本系統支援透過環境變數集中管理外部服務連結：

### 可配置參數清單

| 環境變數名稱 | 類型 | 說明 | 範例 |
| :--- | :--- | :--- | :--- |
| `GOOGLE_APP_SCRIPT_URL` | 字串 (URL) | Google Apps Script Web App 後端端點網址（須以 `/exec` 結尾） | `https://script.google.com/macros/s/AKfycb.../exec` |

### 本地環境設定方式

1. 複製專案根目錄的 [`.env.example`](.env.example) 為 [`.env`](.env)：
   ```bash
   cp .env.example .env
   ```
2. 開啟 [`.env`](.env)，填入您的 Google Apps Script 網址：
   ```env
   GOOGLE_APP_SCRIPT_URL=https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/exec
   ```
3. **環境載入機制**：
   - **透過 HTTP 伺服器啟動（如 Live Server、`serve`、GitHub Pages）**：系統啟動時會自動讀取 `.env` 並套用至雲端同步連線。
   - **直接雙擊 `index.html`（`file://` 協議）**：由於瀏覽器本機安全性原則限制讀取本機檔案，您可直接在 [`env.js`](env.js) 中設定 `GOOGLE_APP_SCRIPT_URL`，雙擊開啟時亦能自動讀取。

## ☁️ Google 試算表 (Google Sheets) & Google Apps Script 雲端資料庫設定教學

本系統採用 **Google 試算表 (Google Sheets)** 與 **Google Apps Script (GAS)** 作為免費、免維護的無伺服器雲端後端。

### 💡 雲端架構特色
1. **雙層儲存機制（離線優先 + 雲端自動同步）**：
   - **本機 LocalStorage**：即便學校網路不穩或斷線，導師依然可以即時登記與操作，絕無延遲。
   - **Google 試算表雲端備份**：日常登記、修改名冊或切換段考時，系統會在背景自動同步備份到 Google Sheets，確保資料永不遺失。
2. **自動產製人類可讀的試算表工作表**：
   - 每次同步時，除了在【`⚙️_系統總資料庫`】以 JSON 完整保存系統結構（保證 100% 完整還原）外，後端會自動產製並更新以下試算表工作表：
     - **【`📋_常規登記流水帳`】**：按時間倒序列出每筆違規或表揚事由（登記序號、日期、班級、段考、座號、姓名、代碼、類別、項目、登記人與備註說明），學務處可直接使用試算表的篩選與列印功能；
     - **【`👥_各班學生名冊與代碼`】**：列出各班學生座號、姓名、家長查詢專屬隨機代碼、當前段考累計優缺點次數與距 15 次警告剩餘次數；
     - **【`⚙️_常規項目設定`】**：列出各班自訂的加扣分常規項目清單。
3. **跨裝置無縫同步**：
   - 無論辦公室桌機、個人筆電或手機，只要設定相同的 Google Apps Script Web App API 網址，即可隨時雙向同步最新資料。

### 🛠️ Step-by-Step 雲端設定步驟教學

#### 步驟 1：建立 Google 試算表
1. 前往 [Google 雲端硬碟](https://drive.google.com/) 或在瀏覽器輸入 [sheets.new](https://sheets.new) 建立一份新的 Google 試算表。
2. 將試算表命名為：**「115學年度學生生活常規優缺點管理資料庫」**（或自訂名稱）。

#### 步驟 2：開啟 Google Apps Script 編輯器
1. 在試算表上方選單點選 **「擴充功能」(Extensions)** ➔ **「Apps Script」**。
2. 瀏覽器會自動開啟 Google Apps Script 程式碼編輯器。

#### 步驟 3：貼上後端程式碼
1. 開啟本專案目錄中的 **[google-apps-script.js](google-apps-script.js)** 檔案，將所有內容完整複製。
2. 回到 Apps Script 編輯器，刪除編輯器內預設的 `function myFunction() {}`。
3. 將複製的程式碼完整貼上至 `Code.gs`（或 `程式碼.gs`）中。
4. 點選上方的 **「儲存專案」(💾)** 圖示。

#### 步驟 4：部署為網頁應用程式 (Web App) —— 關鍵步驟！
1. 點擊右上角藍色的 **「部署」(Deploy)** 按鈕 ➔ 選擇 **「新增部署作業」(New deployment)**。
2. 在彈出的視窗左側齒輪圖示點選 **「選取類型」** ➔ 選擇 **「網頁應用程式」(Web app)**。
3. 填寫部署設定（**請務必依照以下設定，否則無法連線**）：
   - **說明**：常規管理系統 API v1
   - **以這個身分執行 (Execute as)**：選擇 **「我 (Me - 您的 Google 帳號)」**
   - **誰可以存取 (Who has access)**：⚠️ **務必選擇「所有人 (Anyone)」**  
     *(說明：此設定允許前端網頁透過 HTTPS 存取後端 API，不會公開您的 Google 帳號密碼)*
4. 點擊右下角 **「部署」** 按鈕。
5. **首次授權流程**（Google 系統安全性審查）：
   - 點選 **「審查權限」(Review Permissions)**。
   - 點選您的 Google 帳號。
   - 若出現「Google 尚未驗證這個應用程式」警示，請點選左下方 **「進階 (Advanced)」** ➔ 點擊 **「前往『未命名專案』(不安全)」**。
   - 點選 **「允許 (Allow)」** 授權存取試算表權限。
6. 授權完成後，畫面會顯示 **「網頁應用程式網址 (Web App URL)」**，格式如下：
   ```text
   https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/exec
   ```
7. 點擊 **「複製」** 此網址。

#### 步驟 5：在系統前端設定連線
本系統支援兩種設定方式：**「透過環境變數 (.env) 預先配置」** 或 **「於系統介面手動輸入」**。

##### 方法 A：透過環境變數 (.env) 設定（推薦）
在專案根目錄編輯 [`.env`](.env) 或 [`env.js`](env.js)：
```env
GOOGLE_APP_SCRIPT_URL="https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/exec"
```
系統啟動時會自動抓取此環境變數作為預設後端連結。

##### 方法 B：於系統前端介面手動設定
1. 開啟本系統首頁（[index.html](index.html)）。
2. 在頂端導覽列點選 **「☁️ 雲端同步」** 狀態按鈕，即可開啟 **「☁️ Google 試算表雲端同步設定」** 視窗（亦可於「管理中心」➔「安全密碼與維護」中點選）。
3. 將剛才複製的 Web App 網址貼入 **「Google Apps Script 網頁應用程式網址」** 輸入框。
4. 點擊 **「🧪 測試連線」**：
   - 系統將會向 Google 伺服器發送測試 Ping。
   - 出現「連線成功！試算表：...」提示，且狀態燈號轉為 **「🟢 連線正常」** 即代表一切就緒！
5. 點擊 **「💾 儲存網址設定」**。
6. 點擊 **「☁️ 立即上傳備份至試算表」**：
   - 系統會自動將本機現有的班級、名冊、學生代碼、自訂項目等完整上傳至 Google 試算表。
   - 此時切換至您的 Google 試算表，會發現系統已經自動建立了多個格式完整的試算表工作表！

#### 步驟 6：日常使用與自動同步
- **⚡ 自動延遲同步**：日常在導師工作台登記缺點、修改名冊或新增項目時，系統會自動在「閒置 2 秒內」自動同步更新至 Google 試算表，狀態燈號會即時提示「🔄 同步中... ➔ 🟢 雲端已連線」。
- **🔄 更換電腦/跨裝置同步**：在另一台電腦開啟系統時，只要設定相同的 Web App 網址，點擊「☁️ 從試算表下載覆蓋」，即可在 1 秒內同步載入本校所有最新資料！

## 🤖 GitHub Actions 自動部署至 GitHub Pages

本專案已內建完整的 GitHub Actions 自動化部署工作流程檔案（[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)），每次推送程式碼至 `main` 分支時，即可自動部署至 GitHub Pages，並將設定的環境變數自動注入前端！

### 📋 部署操作流程

#### 步驟 1：在 GitHub Repository 設定 Secrets 環境變數
1. 進入您的 GitHub 專案頁面（Repository）。
2. 點選上方頁籤 **「Settings」**（設定）。
3. 在左側選單依序點擊 **「Secrets and variables」** ➔ **「Actions」**。
4. 在「Repository secrets」區塊點擊 **「New repository secret」**：
   - **Name**：輸入 `GOOGLE_APP_SCRIPT_URL`
   - **Secret**：貼上您從 Apps Script 部署取得的 Web App 網址（例如：`https://script.google.com/macros/s/AKfycb.../exec`）
5. 點擊 **「Add secret」** 完成儲存。

> 💡 **安全提示**：使用 GitHub Secrets 可確保您的 Google Apps Script 網址不會直接暴露在 Git 公開原始碼提交歷史中。

#### 步驟 2：開啟 GitHub Pages 的 GitHub Actions 來源
1. 依然在專案的 **「Settings」** 頁面中，點選左側選單的 **「Pages」**。
2. 在 **「Build and deployment」** 區塊：
   - **Source** 下拉選單中，選擇 **「GitHub Actions」**。
3. 儲存設定。

#### 步驟 3：推送程式碼自動觸發部署
1. 將專案變更提交並推送至 GitHub 的 `main` 分支：
   ```bash
   git add .
   git commit -m "feat: setup routine management system with auto deploy"
   git push origin main
   ```
2. 進入 GitHub 專案上方的 **「Actions」** 頁籤，即可看到 `Deploy to GitHub Pages` 工作流程正在自動執行。
3. 流程執行完成後，您會在該 Action 詳細頁或 Settings ➔ Pages 中看到已發布的專屬網址：
   ```text
   https://<您的GitHub帳號>.github.io/<儲存庫名稱>/
   ```
4. 點開網址即可直接使用！系統會自動讀取您注入的 `GOOGLE_APP_SCRIPT_URL`，立即享受雲端自動同步與學生家長在線查詢！

### ❓ 常見問題排解 (FAQ)

- **Q1：點擊「測試連線」時顯示失敗或無法連線？**  
  - 請檢查 Apps Script 部署時的「誰可以存取 (Who has access)」是否選成了「僅限我自己」。必須設定為 **「所有人 (Anyone)」**。  
  - 請確認網址結尾是否為 `/exec`，而非 `/dev` 或試算表本身的 `/edit` 網址。
- **Q2：修改了 `google-apps-script.js` 程式碼後，如何更新生效？**  
  - 在 Apps Script 編輯器中修改並存檔後，點選右上角「部署」➔「管理部署作業」➔ 點選筆型圖示「編輯」➔「版本」下拉選單選擇「新版本」➔ 點擊「部署」。
- **Q3：可以直接在 Google 試算表裡手動修改資料嗎？**  
  - 【📋_常規登記流水帳】與【👥_各班學生名冊與代碼】主要供學務處與導師即時查閱、列印、篩選使用。建議透過系統前端操作以進行修改與登記，以確保試算表與自訂項目的資料結構完整性。
- **Q4：GitHub Pages 部署後出現 404 或未套用最新環境變數？**  
  - 請至 GitHub Repository 的 **Settings ➔ Pages** 確認 Source 是否已切換為 **「GitHub Actions」**。  
  - 若剛新增或更新了 Secret，請至 **Actions** 頁面手動點擊「Run workflow」重新觸發一次部署即可生效。
