# 培英國中 學生常規優缺點管理系統 (導師工作台 & 學生家長查詢專區)

專為國中導師日常班級經營量身打造的現代化常規管理�## 🌟 核心特色與功能說明

### 0. 首頁智慧身分分流大廳 (Landing Portal)
- **進入頁面即時分流**：首頁直覺呈現兩大主要入口，供使用者依身分快速切換：
  - **👨‍🏫 導師工作台**：選定班級後直接進入日常常規登記、座號盤與總表管理。
  - **👨‍👩‍👧 學生 / 家長查詢專區**：免姓名、免密碼，僅憑個人隨機代碼登入，保障隱私安全。
- **隨時一鍵切換**：在各個頁面頂部導覽列皆有「🏠 返回身分分流」或點擊品牌 Logo 即可回到分流大廳。

### 1. 獨立校務管理者登入與系統管理中心 (Admin Console)
- **獨立管理者入口與專屬密碼**：
  - 管理者入口獨立設置於分流大廳頁尾及頂部導航列，避免與一般師生功能混雜。
  - 具備專屬密碼保護（**系統初始預設密碼：`admin888`**），登入後可於管理設定中隨時變更密碼。
- **幫所有老師進行頁面管理與基本資料設定**：
  - **👨‍💻 進入工作台代管模式**：管理者可一鍵以任何一位老師的身分進入其工作台，直接代為操作、登記、檢視總表或排解問題，並可隨時一鍵返回管理中心。
  - **🏫 班級與老師基本資料維護**：在管理中心直接編輯班級名稱、導師姓名、學校名稱與學生人數上限（建議標準 35 人），或新增/刪除班級。
  - **👥 各班學生名冊與代碼管理**：集中管理全校任一班級的 1 ~ 35 號名冊，支援批次從 Excel 貼上、單一/全班代碼重整、列印家長通知小卡。
  - **📢 常規項目全域標準同步**：管理者設定一套標準校規項目後，可一鍵同步套用至全校所有老師的班級中，省去各班重複輸入的時間。
  - **📅 段考週期集中管理**：支援單班切換或「全校統一開啟新段考」，全校班級常規即時歸零並重新累計。
  - **💾 全校資料備份與還原**：一鍵匯出全校所有班級 JSON 完整備份檔，保障資料安全。

### 2. 每日快速常規登記 (座號 1 ~ 35 號)
- **1 ~ 35 號互動座號盤**：大按鈕設計，支援單選、多選、全選或輸入座號多選（如 `1, 3, 5-8`），在教室觸控螢幕或手機上點選極為流暢。
- **即時數值顯示**：每個座號卡片上即時顯示該生在「目前段考」的缺點與優點累計數；若累積達 15 次，座號盤會亮起紅色警戒框與驚嘆號。
- **缺點 / 優點獨立登記**：依照需求無功過相抵，各自分立記錄。
- **即時撤銷流水帳**：右下方顯示最近登記的常規流水帳，若不小心手殘按錯，可一鍵點選「撤銷」立即移除紀錄。

### 3. 學生/家長專屬代碼查詢專區 (個資隱私保障)
- **隨機專屬代碼**：每位同學由系統自動生成一組獨一無二的專屬英數代碼（例如 `PY801-02B`）。
- **零個資外洩風險**：家長與學生無需輸入真實姓名或身分證字號，僅需輸入該代碼即可查詢。
- **個人專屬常規歷程**：登入後可查看當前段考的缺點次數、優點次數、距離 15 次警告尚餘次數，以及每一筆詳細的違規/表揚時間與備註說明。完全看不到其他同學的紀錄，避免比較爭議。
- **一鍵列印家長通知小卡**：導師可在後台點選「🖨️ 列印家長代碼通知小卡」，自動排版產生 A4 紙張大小的 35 張裁切條，方便印出貼於聯絡簿上發給家長。

### 4. 缺點累積滿 15 次警告提醒與生教陳報
- **15 次門檻預警系統**：
  - 累積滿 15 次：系統即時跳出提醒視窗，導覽列亮起紅色動態警示 Badge，首頁橫幅以紅色高對比警示。
  - 接近 12 ~ 14 次：顯示黃色警戒標籤，提醒導師可提早聯絡家長或個別晤談。
- **生教組警告陳報單一鍵生成**：點擊「📄 開立警告單」，系統會自動格式化整理該生班級、座號、姓名、所有違規日期與事由流水帳，並備有導師、生教組、學務主任簽章欄，可直接列印送出懲處！

### 5. 段考週期累積與歸零機制 (約 1 個月)
- **無功過相抵機制**：優點與缺點各自獨立累計，缺點不會被優點扣減。
- **段考歸零重計**：導師在段考結束後，可一鍵新增或切換至「第2次段考」、「第3次段考」，全班的常規累積即時歸零並重新統計。
- **歷史紀錄永久保存**：過去段考的每一筆紀錄皆完整保留，導師在「全班常規總表」中可隨時切換查閱歷次段考或「全學期總計」。

### 6. 學生基本資料庫管理 (上限 35 人)
- **座號 1 ~ 35 號名冊**：支援直接在表格中點選修改姓名。
- **Excel 批次貼上匯入**：點選「📋 批次貼上姓名」，直接從 Excel 或學籍系統複製 35 位名冊貼上，一秒完成名冊建置。
- **代碼隨機重設**：可隨時單獨或全班重新隨機生成代碼。

### 7. 自訂常規項目功能
- 導師可自由新增、修改、刪除自己班級的常規項目：
  - **缺點類預設**：遲到進教室、未交作業、聯絡簿未帶、上課擅自喧嘩、趴睡、服裝不整、打掃偷懶、座位髒亂、走廊奔跑、態度不佳等。
  - **優點類預設**：熱心助人、打掃認真、課堂發言優良、作業整潔獲甲上、拾金不昧、擔任幹部盡責、維護秩序等。
- 支援分類標籤（如：課堂秩序、學業常規、生活衛生、品德態度）與預設次數。

### 8. 多班級與多老師資料庫支援
- 支援建立多個班級資料庫（如：8年1班、8年2班、705班...），不同老師可各自管理自己的班級，資料互不干擾。
- **資料備份與轉移**：支援「📥 下載全系統備份 (JSON)」與「📤 匯入還原備份」，老師可輕鬆將資料從學校電腦備份回傳至個人筆電。
- **匯出 Excel (CSV)**：全班總表支援一鍵匯出為標準 CSV 格式，方便用 Excel 進行統計與存查。後台點選「🖨️ 列印家長代碼通知小卡」，自動排版產生 A4 紙張大小的 35 張裁切條，方便印出貼於聯絡簿上發給家長。

## 🚀 如何開啟與使用

本系統採用純前端無伺服器架構（Vanilla HTML5 + Modern CSS + ES6 JavaScript + LocalStorage 離線持久化）：

1. **直接開啟使用**：
   - 在本專案資料夾中，直接雙擊滑鼠左鍵開啟 [`index.html`](file:///c:/Yong/永豪桌機_培英國中/115-1/優缺點登記APP開發/index.html)。
   - 支援所有現代瀏覽器（Google Chrome、Microsoft Edge、Safari 等）。
   - **完全不需安裝 Node.js、Python 或任何伺服器**，雙擊即可直接離線使用！
2. **網路部署（若想讓學生與家長在家查詢）**：
   - 可將此資料夾檔案上傳至 **GitHub Pages**、**Google Cloud Storage** 或學校內部網頁伺服器，即可獲得專屬網址讓全班家長隨時上線查詢！
