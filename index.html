安裝此系統至手機或電腦

無需經過 App 商店審查，一鍵加入桌面，享受全螢幕原生 App 體驗！

🍎 iPhone / iPad
  1. 以 Safari 瀏覽器 開啟本系統網址
  2. 點擊螢幕下方（或上方）的 分享按鈕 􀈂 分享
  3. 在選單中向下滑動，點選 「加入主畫面」 ➔ 按下右上角「新增」
  4. 手機桌面即可看到專屬 「培英優缺點」App 圖示，點開即是全螢幕！
🤖 Android 手機 / 平板
  1. 以 Chrome 瀏覽器 開啟本系統網址
  2. 點擊網址列右上方 三點選單（⋮）
  3. 點選 「安裝應用程式」 或 「加到主螢幕」
  4. 確認安裝後，桌面將自動生成 App 圖示，支援離線開啟！
💻 電腦 (Windows / Mac)
  1. 以 Chrome 或 Edge 瀏覽器 開啟本網址
  2. 在上方網址列最右側，會看見 「安裝應用程式」電腦小圖示（或點右上角「…」➔「應用程式」➔「安裝此網站為應用程式」）
  3. 點擊「安裝」後，電腦桌面和開始功能表會自動建立捷徑，擁有獨立視窗！
💡 安裝後離線亦可操作登記，連網時自動同步更新
